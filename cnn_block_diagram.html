🔓 Decode output (SW)

// Bước 1: dequantize int8 → float logit out_zp = -2 out_scale = 0.066526 logit = (out_i8 - out_zp) × out_scale = (out_i8 + 2) × 0.066526 // Bước 2: sigmoid (chỉ cần trong SW/CPU) prob = 1.0 / (1.0 + exp(-logit)) // Bước 3: so sánh // prob < 0.01 → FATIGUE (logit < -4.6) // prob ≥ 0.01 → ACTIVE

⚡ ASIC Shortcut — không cần FPU

Không cần tính sigmoid trong hardware! Chỉ cần so sánh out_i8 với threshold:
// prob < 0.01 ↔ logit < −4.60 // logit = (out_i8 + 2) × 0.066526 // -4.60 = (out_i8 + 2) × 0.066526 // out_i8 = -4.60/0.066526 - 2 ≈ -71 // → Hardware chỉ cần: assign is_fatigue = (out_i8 < -8'sd71); // 1 comparator, 0 FPU, 0 multiplier!

📊 Full decode pipeline

// int8 raw output → classification Step 1: int8 → logit (float) logit = (out_i8 − (−2)) × 0.066526 Step 2: sigmoid → prob [0,1] prob = 1 / (1 + exp(−logit)) Step 3: phân loại if prob < 0.01: FATIGUE 😴 (mắt nhắm) else: ACTIVE 😊 (mắt mở) ──────────────────────────────── Ví dụ — mắt nhắm: out_i8 = −120 logit = (−120 + 2) × 0.066526 = −7.85 prob = 1/(1+e^7.85) ≈ 0.00039 → FATIGUE Ví dụ — mắt mở: out_i8 = −40 logit = (−40 + 2) × 0.066526 = −2.53 prob = 1/(1+e^2.53) ≈ 0.074 → ACTIVE

⚡ ASIC integer comparison

// Không cần FPU, không cần sigmoid // Threshold: out_i8 < -71 → FATIGUE module drowsiness_classifier ( input signed [7:0] out_i8, output is_fatigue, output is_active ); localparam THRESHOLD = -8'sd71; assign is_fatigue = (out_i8 < THRESHOLD); assign is_active = ~is_fatigue; endmodule
1 signed comparator = toàn bộ phân loại. Đây là lý do INT8 quantization lý tưởng cho ASIC — loại bỏ hoàn toàn FPU.

🔄 Datapath hoàn chỉnh qua 1 Conv Layer

┌─────────────────────────────────────────────────────────────────────────┐ │ CONV PE — 1 output channel 'co' │ │ │ │ Input SRAM ──→ [ − inp_zp ] ──→ ┐ │ │ int8 X[h,w,ci] int16 x_adj ├──→ MUL (int8 × int16 → int32) │ │ │ │ │ │ Weight ROM ──────────────────────┘ ↓ │ │ int8 W[co,h,w,ci] Σ Accumulate (int32) │ │ × K×K×Cin steps │ │ │ │ │ Bias ROM ───────────────────────────────→ + int32 │ │ int32 b[co] │ │ │ ↓ │ │ M_int32 ROM ────────────────────────────→ × (int32 × int32 → int64) │ │ M_int32[co] │ │ │ ↓ │ │ Shift ROM ──────────────────────────────→ >>> arithmetic shift │ │ shift[co] int64 → int32 │ │ │ │ │ out_zp ─────────────────────────────────→ + (int32) │ │ │ │ │ clip(−128, 127) → int8 │ │ │ │ │ ReLU (nếu có) → [0,127] │ │ │ │ │ Output SRAM int8 Y[or,oc,co] │ └─────────────────────────────────────────────────────────────────────────┘

📋 Các bước chi tiết

1
Load X[h,w,ci] từ Input SRAM (int8). Trừ inp_zp → x_adj (int16 safe vì zp có thể = ±128).
2
Load W[co,kh,kw,ci] từ Weight ROM (int8). Weight zero_point = 0 nên không cần trừ.
3
Nhân: product = x_adj × w (int32). Cộng dồn vào acc (int32) cho tất cả K×K×Cin bước.
4
Cộng bias: acc += bias[co] (int32 + int32 → int32). Bias đã fold BN vào.
5
Requantize: scaled = (int64)acc × M_int32[co] — bắt buộc dùng int64. Sau đó arithmetic right shift total_shift.
6
Clip: out = clip(shifted + out_zp, -128, 127). Nếu có ReLU: out = (out < 0) ? 0 : out.
7
Ghi Y[or,oc,co] vào Output SRAM (int8). Output này là input cho layer tiếp theo.

⚠️ Critical Implementation Notes

int64 là bắt buộc ở bước nhân M_int32. Nếu dùng int32, sẽ overflow và kết quả sai hoàn toàn.
inp_zp khác nhau từng layer — không phải luôn luôn là −128. Layer đầu tiên dùng −128, các layer sau dùng zero point của intermediate activation (lấy từ layer_trace.py).
Arithmetic right shift (>>>) không phải logical shift. Verilog: dùng $signed(x) >>> n.
MaxPool không requantize — scale/zp giữ nguyên từ Conv output.

Module 1 — MAC + Accumulator

// MAC unit: 1 multiply-accumulate step module mac_unit ( input wire clk, rst, en, input wire signed [7:0] weight, // int8 weight input wire signed [7:0] input_val, // int8 input input wire signed [7:0] inp_zp, // zero point (e.g. -128) output reg signed [31:0] acc // int32 accumulator ); wire signed [8:0] x_adj = input_val - inp_zp; // 9-bit wire signed [16:0] product = weight * x_adj; // 17-bit always @(posedge clk) begin if (rst) acc <= 32'sd0; else if (en) acc <= acc + {{15{product[16]}}, product}; // sign-extend end endmodule

Module 2 — Requantizer (per-channel)

// Requantizer: acc(int32) → out(int8) module requantizer #( parameter [31:0] M_INT32 = 32'd765562943, // từ REQUANT_PARAMS parameter [5:0] TOTAL_SHIFT = 6'd39, parameter signed [7:0] OUT_ZP = -8'sd2 ) ( input wire signed [31:0] acc_biased, // sau cộng bias input wire use_relu, // 1=Conv, 0=FC2/output output wire signed [7:0] out_q // int8 result ); wire signed [63:0] scaled = $signed(acc_biased) * $signed(M_INT32); wire signed [31:0] shifted = $signed(scaled) >>> TOTAL_SHIFT; wire signed [31:0] with_zp = shifted + OUT_ZP; // Clip to int8 wire signed [7:0] clipped = (with_zp > 127) ? 8'sd127 : (with_zp < -128) ? -8'sd128 : with_zp[7:0]; // ReLU: set negative to 0 assign out_q = (use_relu && clipped[7]) ? 8'd0 : clipped; endmodule

Module 3 — MaxPool 2×2

// MaxPool 2×2 stride=2 — signed int8 comparison module maxpool2x2 ( input wire signed [7:0] a, b, c, d, // 4 pixels of 2×2 window output wire signed [7:0] y // max value ); wire signed [7:0] ab = ($signed(a) > $signed(b)) ? a : b; wire signed [7:0] cd = ($signed(c) > $signed(d)) ? c : d; assign y = ($signed(ab) > $signed(cd)) ? ab : cd; endmodule // Scale & ZP unchanged — no requantization needed

Module 4 — Output Classifier (no FPU)

// So sánh int8 output với threshold — thay thế sigmoid // Threshold: out_i8 < -71 → FATIGUE // Derivation: prob=0.01 → logit=-4.60 → (x+2)*0.066526=-4.60 → x≈-71 module drowsiness_classifier ( input wire signed [7:0] out_i8, output wire fatigue, // 1 = mắt nhắm output wire active // 1 = mắt mở ); localparam signed [7:0] THRESHOLD = -8'sd71; assign fatigue = ($signed(out_i8) < $signed(THRESHOLD)); assign active = ~fatigue; endmodule

Module 5 — GAP (Global Average Pool)

// GAP 8×8: sum 64 pixels → divide by 64 (= shift 6) module gap_8x8 ( input wire clk, rst, en, input wire signed [7:0] pixel_in, // 1 pixel per cycle input wire last_pixel, // pulse khi đủ 64 output reg signed [7:0] avg_out, // int8 average output reg valid ); reg signed [13:0] sum; // 14-bit: 64 × 127 = 8,128 wire signed [7:0] shifted = $signed(sum) >>> 6; // ÷ 64 always @(posedge clk) begin if (rst) begin sum <= 0; valid <= 0; end else if (last_pixel) begin avg_out <= shifted; valid <= 1; sum <= pixel_in; end else if (en) begin sum <= sum + pixel_in; valid <= 0; end end endmodule // Lặp lại 128 lần (128 channels) — dùng 1 module + mux channel
