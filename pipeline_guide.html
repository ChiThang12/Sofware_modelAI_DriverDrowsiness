⚙️ normalize_to_fixed_point() — Hàm quan trọng nhất
def normalize_to_fixed_point(img_uint8): """uint8 [0,255] → int8 Q0.7 [0,127]""" # Chỉ cần 1 bit-shift phải # 255 >> 1 = 127, 128 >> 1 = 64, 0 >> 1 = 0 fixed_point = (img_uint8.astype(np.int16) >> 1).astype(np.int8) # Clip đảm bảo range hợp lệ fixed_point = np.clip(fixed_point, 0, 127) return fixed_point
Tại sao dùng int16 trước? Nếu uint8 >> 1 trực tiếp, NumPy có thể gây tràn số. Cast sang int16 trước, shift, rồi mới cast về int8 để an toàn.
🔍 verify_asic_friendly() — Các điều kiện ASIC
1
Power-of-2 dimensions
(h & (h-1)) == 0 — 128 là 2^7. ASIC dùng bit-shift addressing. Kích thước 145×145 (cũ) không thỏa điều kiện này.
2
dtype == int8
ASIC datapath 8-bit. float32 tiêu tốn 4× bộ nhớ và cần FPU.
3
Range [0, 127]
Grayscale ảnh không có giá trị âm. int8 âm được dành cho trường hợp khác (intermediate activations). Input layer dùng [0, 127].
4
Shape == 128×128
Phải khớp với IMG_SIZE trong config. Model được build với input_shape=(128,128,1).

preprocess_data_asic.py

Batch processing toàn bộ dataset. Kết hợp MediaPipe face mesh với ASIC preprocessing. Có caching để không phải chạy lại từ đầu.

🔄 PIPELINE XỬ LÝ TỪNG ẢNH
1
cv2.imread() — Load ảnh BGR
OpenCV đọc ảnh dưới dạng BGR (không phải RGB). Giữ nguyên BGR cho MediaPipe.
2
Haar Cascade — Detect face bounding box
haarcascade_frontalface_default.xml. Scale factor 1.3, min neighbors 5. Nếu không detect được face → dùng toàn bộ ảnh gốc.
face_cascade.detectMultiScale(img, 1.3, 5)
3
Crop ROI — Cắt vùng mặt
roi_color = img[y:y+h, x:x+w] — lấy vùng mặt từ ảnh gốc. Giữ nguyên màu (BGR) cho bước MediaPipe tiếp theo.
4
⭐ FaceMesh.process() — Phát hiện landmarks TRÊN ẢNH MÀU
MediaPipe FaceMesh cần ảnh RGB để hoạt động chính xác. 468 landmarks đặc biệt vùng mắt được detect.
5
⭐ draw_landmarks() — Vẽ landmarks WHITE lên ROI màu
Quan trọng: vẽ TRƯỚC khi chuyển grayscale. Landmarks (trắng) sẽ "hòa tan" vào texture ảnh khi resize.
6
cvtColor(BGR→GRAY) — Chuyển grayscale
SAU KHI đã vẽ landmarks. Grayscale giảm dữ liệu 3× (3 channels → 1 channel) và ASIC không cần xử lý màu.
7
resize(128, 128, INTER_AREA) — Thu nhỏ
INTER_AREA tốt nhất khi shrink (giảm kích thước) — tránh aliasing. Landmarks được anti-aliased vào pixel, tạo feature mịn.
8
>> 1 — Q0.7 encode
uint8 [0,255] → int8 [0,127]. Bit-shift đơn giản, ASIC thực hiện trong 1 clock cycle.
⚠️ Tại sao vẽ landmarks TRƯỚC khi grayscale? FaceMesh cần ảnh màu để phát hiện landmarks chính xác. Nếu chuyển grayscale trước → MediaPipe sẽ không hoạt động đúng hoặc miss nhiều landmark. Sau khi vẽ xong mới chuyển grayscale → tất cả landmark được encode vào ảnh như texture trắng.

🔬 BATCHNORM FOLD — Tại sao không implement BN trên ASIC?

BatchNorm có 4 tham số: γ (scale), β (shift), μ (mean), σ (std). Trong inference, tất cả là constants. Ta có thể "fold" vào Conv weight và bias:

// BatchNorm: out = γ × (x - μ) / √(σ²+ε) + β // Fold vào Conv: W_fused = W × γ / √(σ²+ε) // b_fused = β - γ × μ / √(σ²+ε) // Kết quả: Inference = Conv(x, W_fused) + b_fused // → Không cần BN block trong hardware!
TFLite tự động fold BN khi export! Khi chạy TFLiteConverter.convert(), TFLite tự động fuse BatchNorm vào Conv weights. RTL engineer không cần implement BN.

☁️ COLAB
COLAB 4 · STEP 7

Quantization-Aware Training (QAT)

Fine-tune model với fake-quantization nodes để model học weights chịu được quantization error. Kết quả: accuracy drop < 1% sau INT8 export.

🔬 QAT HOẠT ĐỘNG NHƯ THẾ NÀO?
Forward pass: Simulate round(w/scale)*scale — gây quantization error nhân tạo
Backward pass: Straight-Through Estimator — gradient đi thẳng qua hàm round() (coi như identity)
Scale factors học từEMA of observed activations
Weight scaleper-channel, symmetric
Activation scaleper-tensor, asymmetric

// Inference pipeline — không cần FPU Input int8 → Subtract zero_point // 9-bit signed result → MAC (int8 × int9 → int32 acc) // per output channel → + Bias (int32) → Requantize: scaled = acc × M_int32 // int64 ! shifted = scaled >>> total_shift out_q = clip(shifted + zp, -128, 127) → ReLU: clip(out_q, 0, 127) // chỉ 1 comparator → Next layer (int8) // Output layer: KHÔNG cần sigmoid! fatigue = (out_i8 <= zp_out) // zp_out = -2 → logit=0 boundary

📊 REQUANTIZATION FORMULA
// M_float = S_input × S_weight / S_output (per output channel) // Decompose: M_float = M_int32 × 2^(-total_shift) n = floor(log2(M_float)) + 31 // M_int32 near 2^31 M_int32 = round(M_float × 2^n) // int32, MSB ≈ 1 tot_shift= n // typically 30–45 // Verilog implementation: wire [63:0] scaled = $signed(acc) * $signed(M_int32); // int64! wire [31:0] shifted = $signed(scaled) >>> tot_shift; wire [31:0] with_zp = shifted + zp_out; wire [ 7:0] out_q = clip(with_zp, -128, 127);
